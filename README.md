#Student_Performance_analysis
Exploratory data analysis of student performance using Python, Pandas and Data visualisation to identify the factors that influence academic achievement.
This project explores the factors that influence student academic performance using Python and Pandas. The objective is to clean, analyse, and visualise the dataset to identify trends and insights that may contribute to improved educational outcomes.

The project demonstrates core data analysis skills, including data cleaning, exploratory data analysis (EDA), statistical summaries, and data visualisation.

#Objectives

- Explore the student performance dataset.
- Clean and prepare the data for analysis.
- Identify relationships between study habits and exam performance.
- Investigate the impact of attendance, parental involvement, and other factors on student achievement.
- Present findings through clear visualisations.

#Dataset
The dataset contains information about student demographics, study habits, school-related factors, and exam scores.

Some of the variables include:

- Hours Studied
- Attendance
- Parental Involvement
- Access to Resources
- Extracurricular Activities
- Sleep Hours
- Previous Scores
- Motivation Level
- Internet Access
- Family Income
- Teacher Quality
- School Type
- Peer Influence
- Learning Disabilities
- Parental Education Level
- Distance from Home
- Gender
- Exam Score
